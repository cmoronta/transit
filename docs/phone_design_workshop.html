    What Changed in Revision 5

    • Fixed the Top Header in Route Preview: Removed those confusing 3 destination pills at the top! Instead, the top of Route Preview is a clean Google Maps Origin → Destination card (📍 Your location → 🏁 Ponce City Market with a ← back button).
    • Multiple API Routes per Destination (Safest Selected by Default): When you pick a destination, the Transit API returns up to 3 alternative bike itineraries. We compute each itinerary's % protected bike path (from OTP's cycleway/greenway street classes), sort the highest-protected route first as the Default ★, and draw all 3 polylines on the map so you can tap any route on the map or in the drawer to compare.
    • Full-Screen Pull-Up Drawer (Peek · Half · Full): Drag/tap the drawer handle (or use the Drawer: Peek / Half / Full buttons above) to pull the bottom sheet all the way up to cover the whole screen.
